LOCALFIX — FRONTEND PROJECT

1. Extract the ZIP.
2. Open the localfix folder in VS Code.
3. In its terminal, run:

   npm install
   npm run dev

4. Open the URL printed in Terminal.

Requires Node.js 22.12+ or Node 24.
