# GitHub collaboration checklist

This ZIP is the source package. It does not claim an existing remote repository or fabricated teamwork history.

1. Create one repository for the team on GitHub.
2. Inside the extracted project folder, initialize Git if needed, add the files and make a meaningful initial commit.
3. Add the actual remote URL supplied by GitHub and push your initial branch.
4. Invite the real team members as collaborators where access allows.
5. Use feature branches for separate tasks; review changes before merging.
6. Keep the README, requirements and tests aligned with the actual implementation.
7. Do not commit passwords, API keys, private information, node_modules or personal browser data.

Example local commands (substitute your own actual remote URL only):

```bash
git init
git add .
git commit -m "Build LocalFix frontend marketplace"
git branch -M main
```

Add/push the remote using the commands shown on your own GitHub repository page. Assign real responsibilities and record real contributions; do not attribute this generated build to team members without their work/review.
